# Roblox Obby (Unity, WebGL, Яндекс Игры)

Шаблон браузерной игры-обби на **Unity 2022**: игрок проходит полосу препятствий, собирает «робуксы», покупает скины. Подготовлен под публикацию на **Яндекс Играх** (Yandex Games SDK).
Задумывался как основа, из которой можно быстро делать разные обби для веб-платформ.

> Статус: рабочий шаблон. Основная часть разработки: 2023 год.

## Что реализовано
- Управление от первого и третьего лица, зум камеры, `CharacterController`, проверка земли, лестницы, звуки шагов.
- Смерть с рэгдоллом, лава, чекпоинты (`SpawnPoint`), порталы между уровнями с анимацией перехода.
- Валюта и **магазин скинов** (ScriptableObject-данные скинов, загрузчик магазина).
- Интеграция с **Yandex Games SDK**: сохранения прогресса, награды за видеорекламу.
- Меню и игровая сцена.

## Где мой код
`Assets/Scripts` (около 690 строк): `Player`, `Game`, `SkinManager`, `SkinItem`, `SkinShopLoader`, `SpawnPoint`, `Portal`, `Lava`.
Папка `YandexGame` — SDK платформы.

## Стек
Unity 2022 · C# · TextMeshPro · Yandex Games SDK · WebGL

## Запуск
Открыть проект в Unity 2022.2.x, запустить сцену `Menu`.
Для сборки под Яндекс Игры использовать WebGL-билд с SDK.
